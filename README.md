# champions-simulator01

Simulador interativo de mata-mata da Champions League feito com HTML, CSS e JavaScript.
O usuário pode clicar nos times para avançá-los até a final e definir o campeão.

## Preview

Projeto que simula o formato de torneio eliminatório (oitavas → quartas → semi → final) da Champions League.

## Funcionalidades

* Selecionar vencedores clicando nos times
* Avanço automático para a próxima fase
* Estrutura completa de bracket (mata-mata)
* Exibição do campeão com o logo do time
* Layout responsivo com suporte a scroll horizontal em telas menores

## Tecnologias utilizadas

* **HTML5** → Estrutura do bracket
* **CSS3** → Layout, responsividade e estilo visual
* **JavaScript (Vanilla JS)** → Lógica de progressão dos times no torneio

## Estrutura do projeto

champions-bracket
│
├── index.html → Estrutura da página
├── style.css → Estilização e layout
├── script.js → Lógica do simulador
└── Logos → Logos dos times e imagens

## Como usar

1. Abra o arquivo `index.html` no navegador
2. Clique em um time para selecioná-lo como vencedor
3. O time avançará automaticamente para a próxima fase
4. Continue até chegar à final para definir o campeão

## Objetivo do projeto

Este projeto foi criado como prática de manipulação de DOM com JavaScript, organização de layout com Flexbox e construção de interfaces interativas sem frameworks.
